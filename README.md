# eminifybot.com

The landing page for [EminifyBot](https://github.com/emmacyril/EminifyBot): a single static `index.html`, no build step.

Deploy on Vercel with Framework Preset "Other", no build command, output directory `.` (the repo root).
The source of truth is `eminify/site/index.html` in the app repo; this repo mirrors it.
